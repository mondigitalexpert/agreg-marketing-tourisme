# Agrégation Marketing & Tourisme

Application web de préparation à l’agrégation externe Économie-Gestion — option C Marketing, avec un terrain d’application privilégié sur le tourisme.

## Objectifs
- consulter des contenus théoriques structurés ;
- mémoriser auteurs, modèles et concepts ;
- s’entraîner avec QCM, exercices et cas pratiques ;
- travailler sur des cas réels, sourcés et datés ;
- suivre sa progression.

## Principes éditoriaux
- distinction claire entre ressources fournies, contenus de synthèse et sources externes ;
- aucune donnée actuelle non sourcée ;
- date de vérification et liens sources pour les cas réels ;
- priorité aux sources officielles, académiques et professionnelles reconnues.

## Stack
React + Vite.

## Démarrage local
```bash
npm install
npm run dev
```
